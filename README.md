# Screenshot Clip

A browser-based screenshot editor for cropping, annotating, and exporting images.

## Deploy to Vercel

1. Push this project to GitHub.
2. Import the repository into Vercel.
3. Use the default Vite settings:
   - Framework: Vite
   - Build command: npm run build
   - Output directory: dist
4. Deploy.

The project includes a Vercel rewrite rule so deep routes like /dashboard and /editor work correctly in a single-page app.
